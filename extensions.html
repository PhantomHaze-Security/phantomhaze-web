How Extensions Work

📄 Plain Text Extensions

PhantomHaze extensions use the .phext format. They are simple text files that can be imported through Settings → Extensions → Import Extension.

⚙️ Extension Settings

Create configurable toggles, text boxes, dropdowns and number inputs that users can customise directly from Settings.

📑 Custom Pages

Add completely new pages that appear alongside Logs and Web View, allowing you to build dashboards, tools and information panels.

🎨 UI Customisation

Restyle menu items, change colours, replace controls with SVG graphics and create a unique PhantomHaze experience.

🌐 Web Scripts & CSS

Inject JavaScript and CSS into websites to automate tasks, modify layouts or create entirely new functionality.

🛡️ Privacy & Blocking

Block trackers, unwanted domains and other web resources using built-in PhantomScript commands.
